# gaz_calc

Одностраничный веб-сервис «Бизнес-калькулятор энергоцентра» на `React + TypeScript + Tailwind + Recharts`.

## Что умеет
- Сценарии: `Такси (B2C)` и `Бизнес (B2B)`.
- Реактивный расчёт: себестоимость, выручка, прибыль, маржа, окупаемость.
- Автоматическое текстовое резюме для инвестора.
- График накопленной чистой прибыли.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
npm run preview
```
